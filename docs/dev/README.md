# Development notes (historical)

**English:** The files in this folder are the original planning and research notes written *before* and
*during* the first implementation phases of LinuxXR. They are written in **German**, describe the state of the
project at that time, and are **partly outdated** (for example the install steps, the test status and the
"not tested with a real Unity" remarks). For current documentation see the English/German guides:
[README](../../README.md), [INSTALL](../INSTALL.md), [TROUBLESHOOTING](../TROUBLESHOOTING.md),
[ARCHITECTURE](../ARCHITECTURE.md).

**Deutsch:** Die Dateien in diesem Ordner sind die ursprünglichen Planungs- und Recherchenotizen aus der Zeit
*vor* und *während* der ersten Implementierungsphasen von LinuxXR. Sie sind auf **Deutsch** geschrieben,
beschreiben den damaligen Stand und sind **teilweise veraltet** (zum Beispiel Installationsschritte, Teststatus
und Hinweise wie "nicht mit echtem Unity getestet"). Aktuelle Dokumentation: [README.de](../../README.de.md),
[INSTALL.de](../INSTALL.de.md), [TROUBLESHOOTING.de](../TROUBLESHOOTING.de.md).
